👥 일행과 실시간 공유

Firebase Realtime Database(무료)에 데이터를 저장해 모두가 같은 일정을 봅니다. 한 사람만 아래 1회 설정 후 만들어진 링크를 일행에게 보내면 됩니다.

Firebase 설정 (3분)
1. console.firebase.google.com → 프로젝트 만들기
2. Build → Realtime Database → 데이터베이스 만들기 (테스트 모드)
3. 상단의 데이터베이스 URL을 위 칸에 붙여넣기
※ 방 코드를 아는 사람은 누구나 수정 가능하니 링크는 일행에게만 공유하세요. 동시에 수정하면 나중 저장분이 이깁니다.
